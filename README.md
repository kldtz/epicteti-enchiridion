# Epicteti Enchiridion

Two Latin translations of Epictetus' Enchiridion, newly typeset, side by side and aligned by paragraph:

* The Renaissance translation by Angelo Poliziano published in
1497, and
* The scholarly translation by Johannes Schweighäuser pub­lished in 1798.

Physical copy available [here](https://www.amazon.com/Epictetus-Enchiridion-Latin-Parallel-Translations/dp/B0HQP41567).
